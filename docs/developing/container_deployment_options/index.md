# Container deployment options

When your developers publish services to Horizon exchange, they need to specify how the agent communicates with Docker® to deploy the services at run time on the edge node. Your developers must specify the data within the Horizon service definition `deployment` field. For more information, see [Horizon deployment strings](https://open-horizon.github.io/docs/anax/docs/deployment_string/index.md) .
