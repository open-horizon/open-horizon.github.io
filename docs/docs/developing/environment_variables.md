# Environment variables that are passed to services

When the Horizon agent runs your service containers on an edge node, it provides useful data in the form of environment variables. For more information, including a detailed list of these variables and the values that you can expect find for the variables, see [Horizon service environment variables ](../anax/docs/managed_workloads.md#edge-service-vars).
