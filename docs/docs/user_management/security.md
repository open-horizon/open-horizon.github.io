# Security 

Open Horizon (Open Horizon), based on [Open Horizon ](https://github.com/open-horizon), uses several security technologies to ensure that it is secure against attacks and safeguards privacy. For more information about Open Horizon security and roles, see:

* [Security and privacy](./security_privacy.md)
* [Role-based access control](./rbac.md)
* [Open Horizon considerations for GDPR readiness](./gdpr.md)
* [Certificates](../user_management/certificates.md)
* [Disaster recovery](../user_management/disaster_recovery.md)
* [Monitoring management hub components](../user_management/monitoring_infrastructure.md)

For more information about creating workload signing keys if you do not already have your own RSA keys, see [Preparing to create an edge service](../developing/service_containers.md). Use these keys to sign services when you publish them to the exchange and enable the Open Horizon agent to verify that it started a valid workload.
