# Exchange API

Horizon exchange provides a discovery mechanism for Agbots to find agents. Agents use the Horizon exchange REST APIs to register with Horizon exchange. Currently, Horizon exchange REST APIs are not available to users.

See [Horizon Data Exchange Server and REST API ](https://github.com/open-horizon/exchange-api).
