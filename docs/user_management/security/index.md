# Security

Open Horizon (Open Horizon), based on [Open Horizon](https://github.com/open-horizon) , uses several security technologies to ensure that it is secure against attacks and safeguards privacy. For more information about Open Horizon security and roles, see:

- [Security and privacy](https://open-horizon.github.io/docs/user_management/security_privacy/index.md)
- [Role-based access control](https://open-horizon.github.io/docs/user_management/rbac/index.md)
- [Open Horizon considerations for GDPR readiness](https://open-horizon.github.io/docs/user_management/gdpr/index.md)
- [Certificates](https://open-horizon.github.io/docs/user_management/certificates/index.md)
- [Disaster recovery](https://open-horizon.github.io/docs/user_management/disaster_recovery/index.md)
- [Monitoring management hub components](https://open-horizon.github.io/docs/user_management/monitoring_infrastructure/index.md)

For more information about creating workload signing keys if you do not already have your own RSA keys, see [Preparing to create an edge service](https://open-horizon.github.io/docs/developing/service_containers/index.md). Use these keys to sign services when you publish them to the exchange and enable the Open Horizon agent to verify that it started a valid workload.
